### [Когортный анализ благотворителей фонда «АиФ. Доброе сердце»]()

сследование активности и пожертвований благотворителей фонда «АиФ. Доброе сердце». Проект демонстрирует навыки когортного анализа, расчета ключевых метрик (Retention Rate, LTV, MAU, средний чек) и анализа поведения благотворителей для оценки их вовлеченности и регулярности пожертвований.

Стек: SQL, продуктовые метрики, когортный анализ

Сфера деятельности: Charity, Nonprofit
___

### [Проверка гипотез для Яндекс Книги]()
Анализ пользовательской активности в сервисе Яндекс Книги. Проект демонстрирует навыки предобработки данных, сравнения пользовательских групп и проверки статистических гипотез с помощью одностороннего t-теста для двух независимых выборок.

Стэк:  Python, Pandas, Matplotlib, SciPy 

Сфера деятельности: электронные книги и аудиокниги
___ 
### [Анализ A/B-тестирования новой платежной воронки]()

Оценка эффективности новой платежной воронки крупного интернет-магазина. Проект демонстрирует навыки проверки корректности A/B-тестирования, анализа пользовательского поведения, расчета конверсии и проверки статистической значимости различий между группами для оценки влияния изменений на покупки.

Стек: Python, Pandas, Matplotlib, SciPy, Statsmodels

Сфера деятельности: E-commerce, Retail
___

### [Анализ результатов A/B-тестирования интернет-магазина]()

Оценка эффективности нового интерфейса интернет-магазина BitMotion Kit. Проект демонстрирует навыки проверки корректности A/B-тестирования, анализа пользовательского поведения, расчета конверсии и проверки статистической значимости различий между группами.

Сфера деятельности: E-commerce, Retail

### [Анализ продаж видеоигр на PlayStation 3, 4 и 5]()

Исследование продаж видеоигр на консолях PlayStation трех поколений. В рамках исследования изучаются популярность игровых жанров, региональные особенности спроса и связь между оценками игр и объемами продаж. Проект демонстрирует навыки предобработки данных, исследовательского анализа, визуализации, корреляционного анализа и проверки статистических гипотез. 

Стек: Python, Pandas, Matplotlib, Seaborn, SciPy, Phik

Сфера деятельности: Gaming, Entertainment
